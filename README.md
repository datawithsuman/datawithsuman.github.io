## ✨ What is this?

Short, visual lessons you can **play with**, not just read. Every lesson has:

- 🎛️ **Interactive labs**: sliders, toggles and live charts
- ❓ **A quick quiz** to test the key idea
- 🧭 **Step-by-step recipes** for real-world use
- 🎤 **Interview follow-ups** with crisp answers
- 🎬 **A short Reel** version on Instagram and YouTube

Three sections: **Fundamentals**, **AI Engineering** and **Papers**. Pick a track and go in order.

<details>
<summary><b>🛠️ For developers: how this repo is organised</b></summary>

<br>

Plain static files served by GitHub Pages. No build step, no tracking.

```
datawithsuman.github.io/
├── index.html                      landing page
└── ai/interview-prep/              the lessons
    ├── index.html                  lessons home (sections → track cards)
    ├── lessons.js                  sections → tracks → groups → lessons (drives every menu)
    ├── kit/                        shared dark theme, fonts, navigation
    ├── fundamentals/               section page + tracks: machine-learning, deep-learning, llms
    ├── system-design/              section page + tracks: llm-inference, genai-apps, ml-system-design, ml-scenarios, mlops
    ├── papers/                     papers track
    └── <old track folders>/        redirect pages, so old links keep working
```

**Run locally:** clone the repo and open `index.html` in a browser. Everything works offline.

**Add a lesson:** add its folder under its track (e.g. `fundamentals/machine-learning/<slug>/`), then one entry in `lessons.js` (with `group` if the track has sub-sections). The menus, numbering and Previous/Next update automatically. (Update the tables in this README too.)

</details>
