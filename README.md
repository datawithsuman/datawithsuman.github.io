## ✨ What is this?

Short, visual lessons you can **play with**, not just read. Every lesson has:

- 🎛️ **Interactive labs**: sliders, toggles and live charts
- ❓ **A quick quiz** to test the key idea
- 🧭 **Step-by-step recipes** for real-world use
- 🎤 **Interview follow-ups** with crisp answers
- 🎬 **A short Reel** version on Instagram and YouTube

Four tracks: **Fundamentals**, **AI Engineering**, **System Design** and **Papers**. Pick a track and go in order.

<details>
<summary><b>🛠️ For developers: how this repo is organised</b></summary>

<br>

Static files served by GitHub Pages from `docs/`, built by a small Python script. No tracking.

```
datawithsuman.github.io/
├── docs/                 the published site (generated, don't edit by hand)
├── new-site/             the generator: build.py, lesson plans, design assets
└── ai/                   source lesson pages, labs and the roadmap PDF (not published)
```

**Build:** `python3 new-site/build.py` writes the whole site to `docs/`. Then commit and push.

**Add a lesson:** add its source page under `ai/interview-prep/`, one entry in `lessons.js`, one entry in the matching module in `new-site/`, and its plan in the matching `*_plans.py`.

</details>
