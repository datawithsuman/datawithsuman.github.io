CNNs and vision

9 questions on CNNs and vision, from 9 lessons. Pick an answer in your head, then open it.

On the roadmap for: ML Engineering.

  1. Question 1 of 9

    Why does a 3×3 convolution suit images better than a dense layer?

    1. A. It's always more accurate
    2. B. It uses local patterns and shares the same weights across positions, so it needs far fewer parameters
    3. C. It ignores neighbouring pixels
    4. D. It works only on grayscale
    View answer

    ✓ B. It uses local patterns and shares the same weights across positions, so it needs far fewer parameters

    Locality and weight sharing match how images work: an edge looks the same anywhere.

    Lesson: Convolution and Receptive Field

  2. Question 2 of 9

    Input 32×32, kernel 3×3, padding 1, stride 2. What is the output's height and width?

    1. A. 32×32
    2. B. 16×16
    3. C. 15×15
    4. D. 30×30
    View answer

    ✓ B. 16×16

    Output = ⌊(32 − 3 + 2·1) / 2⌋ + 1 = ⌊31/2⌋ + 1 = 16.

    Lesson: Pooling, Stride, Padding and Output Shapes

  3. Question 3 of 9

    Before ResNet, why did much deeper plain networks get worse results, even on training data?

    1. A. Overfitting
    2. B. They were harder to optimise: signals and gradients degraded through many layers
    3. C. Too little data
    4. D. GPUs ran out of memory
    View answer

    ✓ B. They were harder to optimise: signals and gradients degraded through many layers

    Higher training error showed it was an optimisation problem; skip connections fixed it.

    Lesson: ResNets and Skip Connections

  4. Question 4 of 9

    What idea did VGG add to CNN design?

    1. A. Skip connections
    2. B. Stacking small 3×3 convolutions to get a large receptive field with fewer parameters
    3. C. Attention
    4. D. Depthwise convolutions
    View answer

    ✓ B. Stacking small 3×3 convolutions to get a large receptive field with fewer parameters

    Two 3×3 layers see a 5×5 area with fewer weights and an extra non-linearity.

    Lesson: CNN Architectures: AlexNet to ConvNeXt

  5. Question 5 of 9

    You have only a few hundred labelled images. What's the usual approach?

    1. A. Train a CNN from scratch
    2. B. Start from a pretrained model, freeze most layers, and fine-tune the head (then maybe the top layers)
    3. C. Use a random forest on pixels
    4. D. Collect no more data
    View answer

    ✓ B. Start from a pretrained model, freeze most layers, and fine-tune the head (then maybe the top layers)

    Pretrained features transfer well, so small datasets can still reach good accuracy.

    Lesson: Transfer Learning and Fine-Tuning

  6. Question 6 of 9

    How does a Vision Transformer (ViT) process an image?

    1. A. Pixel by pixel with an RNN
    2. B. It splits the image into patches, embeds each patch as a token, and runs a Transformer over them
    3. C. It converts the image to text
    4. D. It uses only convolutions
    View answer

    ✓ B. It splits the image into patches, embeds each patch as a token, and runs a Transformer over them

    With less built-in image bias than a CNN, ViTs usually need more data or pretraining.

    Lesson: Vision Transformers

  7. Question 7 of 9

    How is an object detector usually evaluated?

    1. A. Accuracy
    2. B. Mean average precision (mAP), counting a box as correct when its IoU with the true box passes a threshold
    3. C. RMSE of box sizes
    4. D. Number of boxes
    View answer

    ✓ B. Mean average precision (mAP), counting a box as correct when its IoU with the true box passes a threshold

    IoU decides whether a box matches; mAP summarises precision and recall across classes.

    Lesson: Object Detection

  8. Question 8 of 9

    Which architecture is a classic for image segmentation?

    1. A. AlexNet
    2. B. U-Net: an encoder-decoder with skip connections that keep fine detail for per-pixel labels
    3. C. A plain MLP
    4. D. Word2Vec
    View answer

    ✓ B. U-Net: an encoder-decoder with skip connections that keep fine detail for per-pixel labels

    The decoder upsamples to full resolution, and the skips bring back the edges lost by downsampling.

    Lesson: Image Segmentation

  9. Question 9 of 9

    How can a tiny, invisible change to an image fool a classifier?

    1. A. It can't
    2. B. Shifting each pixel slightly in the direction that raises the loss adds up across thousands of pixels
    3. C. It changes the image size
    4. D. It removes colour
    View answer

    ✓ B. Shifting each pixel slightly in the direction that raises the loss adds up across thousands of pixels

    Methods like FGSM use the gradient to find these adversarial examples.

    Lesson: Interpreting Networks and Adversarial Examples
