  1. Question 1 of 9

    What does ordinary least squares minimise?

    1. A. The sum of absolute residuals
    2. B. The sum of squared residuals
    3. C. The number of wrong predictions
    4. D. The largest residual
    View answer

    ✓ B. The sum of squared residuals

    OLS picks weights that make Σ(yᵢ − ŷᵢ)² as small as possible.

    Lesson: Linear Regression

  2. Question 2 of 9

    Why is ordinary least squares sensitive to outliers?

    1. A. It ignores large errors
    2. B. Squaring makes a large residual count far more than several small ones
    3. C. It uses the median
    4. D. It needs normalised features
    View answer

    ✓ B. Squaring makes a large residual count far more than several small ones

    An error of 10 costs 100, as much as a hundred errors of 1, so outliers pull the line towards them.

    Lesson: Linear Regression

  3. Question 3 of 9

    What is the key difference between Lasso and Ridge?

    1. A. Lasso can set weights exactly to zero; Ridge only shrinks them
    2. B. Ridge selects features; Lasso doesn't
    3. C. Lasso is for classification only
    4. D. They are the same
    View answer

    ✓ A. Lasso can set weights exactly to zero; Ridge only shrinks them

    Lasso's L1 penalty produces sparse models (feature selection); Ridge's L2 penalty keeps every feature but smaller.

    Lesson: Regularized Linear Models

  4. Question 4 of 9

    You have many correlated features and want some feature selection without dropping whole correlated groups at random. Which model fits best?

    1. A. Plain OLS
    2. B. Elastic Net
    3. C. Lasso only
    4. D. No regularisation
    View answer

    ✓ B. Elastic Net

    Elastic Net mixes L1 (sparsity) with L2 (keeps correlated features together, stabilising the choice).

    Lesson: Regularized Linear Models

  5. Question 5 of 9

    Why is logistic regression called regression when it's used for classification?

    1. A. It was named by mistake
    2. B. It fits a linear model to the log-odds of the positive class
    3. C. It predicts continuous labels
    4. D. It uses squared error
    View answer

    ✓ B. It fits a linear model to the log-odds of the positive class

    The linear part predicts log-odds; the sigmoid turns them into a probability, and a threshold makes the class.

    Lesson: Logistic Regression

  6. Question 6 of 9

    What does log-loss punish most?

    1. A. Predictions near 0.5
    2. B. Confident predictions that are wrong
    3. C. Correct predictions
    4. D. Large feature values
    View answer

    ✓ B. Confident predictions that are wrong

    Loss is −log p for the true class; as p → 0 for the true class, the loss grows without limit.

    Lesson: Logistic Regression

  7. Question 7 of 9

    In logistic regression, a feature's coefficient is β = 0.7. What happens when that feature rises by one unit?

    1. A. The probability rises by 0.7
    2. B. The odds are multiplied by e^0.7 ≈ 2
    3. C. The log-loss falls by 0.7
    4. D. Nothing
    View answer

    ✓ B. The odds are multiplied by e^0.7 ≈ 2

    Each unit adds β to the log-odds, which multiplies the odds by e^β.

    Lesson: Logistic Regression

  8. Question 8 of 9

    What does softmax regression do with K classes?

    1. A. Trains K separate unrelated models
    2. B. Turns K scores (logits) into probabilities that sum to 1, trained with cross-entropy
    3. C. Picks the largest feature
    4. D. Uses squared error on one-hot labels
    View answer

    ✓ B. Turns K scores (logits) into probabilities that sum to 1, trained with cross-entropy

    It generalises logistic regression to many classes, and it's the last layer of every LLM, over the vocabulary.

    Lesson: Softmax Regression

  9. Question 9 of 9

    You need to predict the number of insurance claims per customer (0, 1, 2…). Which model fits best?

    1. A. Linear regression
    2. B. Poisson regression, a GLM with a log link
    3. C. Logistic regression
    4. D. k-means
    View answer

    ✓ B. Poisson regression, a GLM with a log link

    Counts are non-negative and skewed. A Poisson GLM models the log of the expected count linearly.

    Lesson: Generalised Linear Models
