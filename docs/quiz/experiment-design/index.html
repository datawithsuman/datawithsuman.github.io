QUIZ

Experiment design

5 questions on Experiment design, from 5 lessons. Pick an answer in your head, then open it.

On the roadmap for: Data Science.

  1. Question 1 of 5

    A new LLM tutor prompt looks better in demos. What's the right primary metric for a production test?

    1. A. How good the demo looked
    2. B. A real user outcome, such as learning progress or task success, with guardrails on cost, latency and safety
    3. C. Response length
    4. D. Number of tokens
    View answer

    ✓ B. A real user outcome, such as learning progress or task success, with guardrails on cost, latency and safety

    Demos are cherry-picked; randomise real users and measure what the product is for.

    Lesson: Test an LLM Prompt in Production

  2. Question 2 of 5

    AI-written email subject lines lost to the old rule-based ones. What's a sensible next step?

    1. A. Ship them anyway
    2. B. Diagnose why: check segments, opens vs later actions, and examples; improve the model, then test again
    3. C. Abandon AI for good
    4. D. Run the same test again until it wins
    View answer

    ✓ B. Diagnose why: check segments, opens vs later actions, and examples; improve the model, then test again

    A loss is information: find where and why it lost before deciding.

    Lesson: Fix a Failing AI Feature

  3. Question 3 of 5

    A feed change affects what a user's friends see. How do you measure its real effect?

    1. A. Randomise individual users as usual
    2. B. Randomise clusters of connected users together, so treatment and control don't spill into each other
    3. C. Ask users
    4. D. Use only offline data
    View answer

    ✓ B. Randomise clusters of connected users together, so treatment and control don't spill into each other

    Cluster (graph) randomisation keeps most interactions within one group.

    Lesson: Measure a Feed Change with Network Effects

  4. Question 4 of 5

    Why write the launch decision rule before the test starts?

    1. A. It's a legal rule
    2. B. So results can't be reinterpreted after the fact; for example, ship if the main metric wins and no guardrail drops beyond an agreed margin
    3. C. To make the test shorter
    4. D. It doesn't matter
    View answer

    ✓ B. So results can't be reinterpreted after the fact; for example, ship if the main metric wins and no guardrail drops beyond an agreed margin

    Deciding after seeing the data invites cherry-picking.

    Lesson: Set a Launch Decision Rule

  5. Question 5 of 5

    What's a core part of a platform that runs hundreds of A/B tests at once?

    1. A. Manual spreadsheets
    2. B. Consistent hash-based assignment, automatic checks such as SRM, shared metric definitions, and a way to run overlapping tests
    3. C. One test at a time
    4. D. A single dashboard for revenue
    View answer

    ✓ B. Consistent hash-based assignment, automatic checks such as SRM, shared metric definitions, and a way to run overlapping tests

    Automation makes tests trustworthy and cheap enough to run many.

    Lesson: Design an Experimentation Platform
