Attention and Transformers

10 questions on Attention and Transformers, from 6 lessons. Pick an answer in your head, then open it.

On the roadmap for: AI Engineering, ML Engineering.

  1. Question 1 of 10

    In self-attention, what do the queries, keys and values do?

    1. A. They're three copies of the same thing
    2. B. A query is matched against every key to get weights, and those weights mix the values
    3. C. Keys hold the output; values are ignored
    4. D. Queries are the labels
    View answer

    ✓ B. A query is matched against every key to get weights, and those weights mix the values

    Each token asks (query) which tokens are relevant (keys) and takes a weighted mix of their content (values).

    Lesson: Self-Attention (Q, K, V)

  2. Question 2 of 10

    Why are attention scores divided by √d before the softmax?

    1. A. To make them positive
    2. B. Dot products grow with dimension d; scaling keeps their spread near 1 so the softmax doesn't saturate
    3. C. To save memory
    4. D. To normalise the values
    View answer

    ✓ B. Dot products grow with dimension d; scaling keeps their spread near 1 so the softmax doesn't saturate

    Without scaling, large scores push the softmax towards one-hot, and gradients become tiny.

    Lesson: Self-Attention (Q, K, V)

  3. Question 3 of 10

    How does the cost of full self-attention grow with sequence length n?

    1. A. Linearly, O(n)
    2. B. Quadratically, O(n²)
    3. C. Logarithmically
    4. D. It doesn't depend on n
    View answer

    ✓ B. Quadratically, O(n²)

    Every token scores every other token, which makes an n × n matrix.

    Lesson: Multi-Head Attention

  4. Question 4 of 10

    Why use several attention heads instead of one big one?

    1. A. It's much cheaper
    2. B. Each head can attend to a different kind of relationship in its own subspace, at about the same total cost
    3. C. Heads replace the feed-forward layer
    4. D. It removes the need for positions
    View answer

    ✓ B. Each head can attend to a different kind of relationship in its own subspace, at about the same total cost

    Splitting d into h heads keeps compute similar while letting heads specialise.

    Lesson: Multi-Head Attention

  5. Question 5 of 10

    Grouped-query attention (GQA) shares keys and values across groups of query heads. What does that mainly save?

    1. A. Training data
    2. B. KV-cache memory at long context
    3. C. Vocabulary size
    4. D. Number of layers
    View answer

    ✓ B. KV-cache memory at long context

    Fewer K/V heads means a smaller cache per token, which matters most when serving long contexts.

    Lesson: Multi-Head Attention

  6. Question 6 of 10

    Without any positional information, what is self-attention's problem with word order?

    1. A. It reads right to left
    2. B. It is permutation-invariant: shuffling the words gives the same set of outputs
    3. C. It only sees the first word
    4. D. It can't handle long words
    View answer

    ✓ B. It is permutation-invariant: shuffling the words gives the same set of outputs

    Attention treats its inputs as a set; positional encodings or RoPE bring order in.

    Lesson: Positional Encodings (incl. RoPE)

  7. Question 7 of 10

    How does RoPE (rotary positional embedding) encode position?

    1. A. By adding a learned vector to each token
    2. B. By rotating queries and keys by angles that depend on position, so their dot product depends on relative distance
    3. C. By sorting the tokens
    4. D. By a separate position model
    View answer

    ✓ B. By rotating queries and keys by angles that depend on position, so their dot product depends on relative distance

    Rotations make the score between two tokens depend on how far apart they are, not on where they sit.

    Lesson: Positional Encodings (incl. RoPE)

  8. Question 8 of 10

    In a standard Transformer block with a 4× feed-forward expansion, where do most of the parameters sit?

    1. A. In the layer norms
    2. B. In the feed-forward (MLP) layers, about two-thirds
    3. C. In the attention softmax
    4. D. In the positional encodings
    View answer

    ✓ B. In the feed-forward (MLP) layers, about two-thirds

    Attention projections are about 4d², and the FFN is about 8d² (d → 4d → d), so the FFN holds roughly two-thirds.

    Lesson: The Transformer Block

  9. Question 9 of 10

    Which pairing is correct?

    1. A. BERT: decoder-only; GPT: encoder-only
    2. B. BERT: bidirectional encoder (masked LM); GPT: causal decoder; T5: encoder-decoder
    3. C. All three are encoder-decoder
    4. D. GPT is bidirectional
    View answer

    ✓ B. BERT: bidirectional encoder (masked LM); GPT: causal decoder; T5: encoder-decoder

    BERT sees both sides to understand text; GPT predicts the next token; T5 encodes an input and decodes an output.

    Lesson: Encoder vs Decoder vs Encoder-Decoder

  10. Question 10 of 10

    What does the causal mask in a decoder do?

    1. A. Hides padding only
    2. B. Stops each token from attending to tokens after it, so training matches next-token generation
    3. C. Drops random tokens
    4. D. Removes the first token
    View answer

    ✓ B. Stops each token from attending to tokens after it, so training matches next-token generation

    Without it, the model would see the answer while learning to predict it.

    Lesson: The Transformer, End to End
