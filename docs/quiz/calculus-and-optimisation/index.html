  1. Question 1 of 9

    y = f(g(x)). What does the chain rule give for dy/dx?

    1. A. f′(x) + g′(x)
    2. B. f′(g(x)) · g′(x)
    3. C. f′(x) · g′(x)
    4. D. f(g′(x))
    View answer

    ✓ B. f′(g(x)) · g′(x)

    Multiply the outer derivative, evaluated at the inner function, by the inner derivative. Backprop applies this layer by layer.

    Lesson: Derivatives, Gradients & the Chain Rule

  2. Question 2 of 9

    Why does neural network training use reverse-mode automatic differentiation?

    1. A. It's more accurate
    2. B. One backward pass gives the gradient of a single loss with respect to millions of parameters
    3. C. Forward mode can't handle matrices
    4. D. It needs no memory
    View answer

    ✓ B. One backward pass gives the gradient of a single loss with respect to millions of parameters

    Reverse mode costs about one pass per output; with one scalar loss and many inputs, it's far cheaper than forward mode.

    Lesson: Automatic Differentiation

  3. Question 3 of 9

    Why does high curvature limit how large the learning rate can be?

    1. A. It doesn't
    2. B. In steep, sharply curved directions a big step overshoots the minimum and bounces or diverges
    3. C. Curvature slows the GPU
    4. D. High curvature means a flat loss
    View answer

    ✓ B. In steep, sharply curved directions a big step overshoots the minimum and bounces or diverges

    A second-order Taylor view shows gradient descent is stable only if the step is below about 2 / (largest curvature).

    Lesson: Taylor Series and Curvature

  4. Question 4 of 9

    What does momentum add to gradient descent?

    1. A. Random noise
    2. B. A running average of past gradients, which speeds up steady directions and damps zig-zagging
    3. C. A second learning rate
    4. D. Exact second derivatives
    View answer

    ✓ B. A running average of past gradients, which speeds up steady directions and damps zig-zagging

    Like a ball rolling downhill, it builds speed along consistent slopes.

    Lesson: Gradient Descent, Momentum & Adam

  5. Question 5 of 9

    What does Adam do differently from plain SGD?

    1. A. It uses the Hessian
    2. B. It adapts each parameter's step size using running averages of its gradients and squared gradients
    3. C. It skips the backward pass
    4. D. It uses a fixed step for all parameters
    View answer

    ✓ B. It adapts each parameter's step size using running averages of its gradients and squared gradients

    Parameters with large, noisy gradients get smaller steps, and rare ones get larger steps.

    Lesson: Gradient Descent, Momentum & Adam

  6. Question 6 of 9

    Why isn't Newton's method used to train large neural networks?

    1. A. It converges too slowly
    2. B. It needs the Hessian, with n² entries, which is far too large to store and invert for millions of parameters
    3. C. It only works on convex losses
    4. D. It can't use gradients
    View answer

    ✓ B. It needs the Hessian, with n² entries, which is far too large to store and invert for millions of parameters

    With 10⁹ parameters the Hessian would have 10¹⁸ entries. Approximations like L-BFGS or Adam are used instead.

    Lesson: Newton's Method and Second-Order Optimisation

  7. Question 7 of 9

    What is special about a convex loss function?

    1. A. It has many local minima
    2. B. Any local minimum is a global minimum, so the starting point doesn't change where you end up
    3. C. It can't be minimised
    4. D. It's always linear
    View answer

    ✓ B. Any local minimum is a global minimum, so the starting point doesn't change where you end up

    Linear and logistic regression are convex; deep networks are not, so initialisation matters there.

    Lesson: Convexity & Local Minima

  8. Question 8 of 9

    PCA finds the direction of maximum variance subject to the direction having length 1. What does the Lagrange multiplier method show?

    1. A. The answer is random
    2. B. The best direction is an eigenvector of the covariance matrix, and the multiplier is its eigenvalue
    3. C. PCA needs labels
    4. D. Constraints can be ignored
    View answer

    ✓ B. The best direction is an eigenvector of the covariance matrix, and the multiplier is its eigenvalue

    Setting the gradient of variance minus λ(‖w‖² − 1) to zero gives Σw = λw.

    Lesson: Lagrange Multipliers and KKT

  9. Question 9 of 9

    An expectation you need is an integral with no closed form. What's the usual approach in ML?

    1. A. Skip it
    2. B. Estimate it by sampling (Monte Carlo): average the function over random draws
    3. C. Use the mode only
    4. D. Set it to zero
    View answer

    ✓ B. Estimate it by sampling (Monte Carlo): average the function over random draws

    Averages over samples converge to the integral; variational methods are another option.

    Lesson: Integrals for ML
