  1. Question 1 of 11

    When would you report the median instead of the mean?

    1. A. When the data is perfectly symmetric
    2. B. When the data is skewed or has outliers, such as incomes
    3. C. Only for categorical data
    4. D. Never, the mean is always better
    View answer

    ✓ B. When the data is skewed or has outliers, such as incomes

    A few billionaires move the mean a lot but barely move the median.

    Lesson: Descriptive Statistics and Outliers

  2. Question 2 of 11

    You study only startups that are still running to find what makes startups succeed. What bias is this?

    1. A. Survivorship bias
    2. B. Recall bias
    3. C. Measurement bias
    4. D. Confirmation bias
    View answer

    ✓ A. Survivorship bias

    The failed startups, which might share the same traits, are missing from your data.

    Lesson: Sampling and Bias

  3. Question 3 of 11

    What does a 95% confidence interval promise?

    1. A. There is a 95% chance the true value is in this particular interval
    2. B. If you repeated the study many times, 95% of the intervals built this way would contain the true value
    3. C. 95% of the data falls inside it
    4. D. The estimate is 95% accurate
    View answer

    ✓ B. If you repeated the study many times, 95% of the intervals built this way would contain the true value

    In frequentist statistics the 95% describes the procedure, not this one interval. The Bayesian credible interval is the one with the first meaning.

    Lesson: Confidence Intervals & the Bootstrap

  4. Question 4 of 11

    What is a p-value?

    1. A. The probability that the null hypothesis is true
    2. B. The probability of seeing data at least this extreme if the null hypothesis were true
    3. C. The probability the result is important
    4. D. The effect size
    View answer

    ✓ B. The probability of seeing data at least this extreme if the null hypothesis were true

    It measures surprise under the null. It says nothing directly about how likely the null is or how big the effect is.

    Lesson: Hypothesis Tests, p-values & A/B Testing

  5. Question 5 of 11

    You check an A/B test every day and stop as soon as p < 0.05. What's the problem?

    1. A. Nothing, it saves time
    2. B. Repeated looks inflate the false-positive rate well above 5%
    3. C. The test loses all power
    4. D. It makes p-values negative
    View answer

    ✓ B. Repeated looks inflate the false-positive rate well above 5%

    Each look is another chance to cross the line by luck. Fix the sample size first, or use a sequential test designed for peeking.

    Lesson: Hypothesis Tests, p-values & A/B Testing

  6. Question 6 of 11

    You measure the same users before and after a change. Which test fits best?

    1. A. A two-sample z-test
    2. B. A paired t-test
    3. C. A chi-squared test
    4. D. ANOVA
    View answer

    ✓ B. A paired t-test

    Pairing compares each user with themselves, which removes between-user variation and gives more power.

    Lesson: T-Tests and Z-Tests

  7. Question 7 of 11

    You want to compare the means of five groups. Why use ANOVA instead of t-tests between every pair?

    1. A. ANOVA is always more accurate
    2. B. Ten separate t-tests inflate the chance of a false positive; ANOVA tests all groups at once
    3. C. t-tests can't compare means
    4. D. ANOVA doesn't need data
    View answer

    ✓ B. Ten separate t-tests inflate the chance of a false positive; ANOVA tests all groups at once

    Five groups make 10 pairs. At 5% each, the chance of at least one false alarm is about 40%.

    Lesson: Chi-Squared Tests and ANOVA

  8. Question 8 of 11

    How does a permutation test build its null distribution?

    1. A. From a normal table
    2. B. By shuffling the group labels many times and recomputing the statistic
    3. C. By bootstrapping one group
    4. D. By assuming equal variances
    View answer

    ✓ B. By shuffling the group labels many times and recomputing the statistic

    If the groups don't differ, labels are exchangeable, so shuffled labels show what differences look like by chance.

    Lesson: Non-Parametric and Permutation Tests

  9. Question 9 of 11

    In a multiple regression, the coefficient on 'years of experience' is 2,000. What does it mean?

    1. A. Experience causes salary to rise by 2,000
    2. B. Each extra year is associated with 2,000 more salary, holding the other features fixed
    3. C. Salary is 2,000 on average
    4. D. 2,000 people were in the data
    View answer

    ✓ B. Each extra year is associated with 2,000 more salary, holding the other features fixed

    Coefficients are partial associations. Calling them causal needs a design that rules out confounders.

    Lesson: Inference for Regression

  10. Question 10 of 11

    A treatment looks better in each hospital separately but worse when you pool the hospitals. What is this?

    1. A. Regression to the mean
    2. B. Simpson's paradox, caused by a confounder such as case severity
    3. C. Survivorship bias
    4. D. A sampling error
    View answer

    ✓ B. Simpson's paradox, caused by a confounder such as case severity

    If one hospital gets sicker patients and uses the treatment more, pooling mixes the groups and flips the trend.

    Lesson: Correlation vs Causation

  11. Question 11 of 11

    You can't run an A/B test, but one city got a feature and a similar city didn't. Which method compares the before-to-after change between them?

    1. A. Difference-in-differences
    2. B. A paired t-test
    3. C. Bootstrapping
    4. D. PCA
    View answer

    ✓ A. Difference-in-differences

    It subtracts the control city's change from the treated city's change, assuming the two would have moved in parallel without the feature.

    Lesson: Causal Inference Without an Experiment
