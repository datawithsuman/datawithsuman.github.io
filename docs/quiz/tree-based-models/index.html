Tree-based models

9 questions on Tree-based models, from 4 lessons. Pick an answer in your head, then open it.

On the roadmap for: ML Engineering, Data Science.

  1. Question 1 of 9

    How does a classification tree choose a split?

    1. A. At random
    2. B. It picks the feature and threshold that most reduce impurity, such as Gini or entropy
    3. C. It always splits on the first feature
    4. D. By the feature with the most values
    View answer

    ✓ B. It picks the feature and threshold that most reduce impurity, such as Gini or entropy

    Each split greedily makes the child nodes as pure as possible. Regression trees reduce variance instead.

    Lesson: Decision Trees

  2. Question 2 of 9

    Why does a very deep decision tree often do badly on new data?

    1. A. It can't fit the training data
    2. B. It memorises noise in the training set (high variance)
    3. C. It uses too few features
    4. D. Trees can't be deep
    View answer

    ✓ B. It memorises noise in the training set (high variance)

    With enough depth every training point gets its own leaf. Limit depth or leaf size, or prune.

    Lesson: Decision Trees

  3. Question 3 of 9

    What makes the trees in a random forest different from each other?

    1. A. Each uses a different loss
    2. B. Each is trained on a bootstrap sample, and each split considers a random subset of features
    3. C. Each tree has a different depth only
    4. D. They're identical
    View answer

    ✓ B. Each is trained on a bootstrap sample, and each split considers a random subset of features

    Both sources of randomness decorrelate the trees, so averaging them cuts variance.

    Lesson: Random Forest

  4. Question 4 of 9

    What is a random forest's out-of-bag error?

    1. A. The training error
    2. B. Error measured on the samples each tree didn't see in its bootstrap sample
    3. C. Error on the test set
    4. D. The error of the worst tree
    View answer

    ✓ B. Error measured on the samples each tree didn't see in its bootstrap sample

    About a third of the rows are left out of each bootstrap, so they act as a free validation set.

    Lesson: Random Forest

  5. Question 5 of 9

    In gradient boosting, what does each new tree learn?

    1. A. The original labels
    2. B. The negative gradient of the loss, which for squared error is the current residuals
    3. C. A random subset of labels
    4. D. The average of the previous trees
    View answer

    ✓ B. The negative gradient of the loss, which for squared error is the current residuals

    Each tree corrects the ensemble's current mistakes, and a learning rate scales its contribution.

    Lesson: Gradient Boosting

  6. Question 6 of 9

    What happens if you keep adding trees to gradient boosting with no early stopping?

    1. A. It can't overfit
    2. B. It can overfit, unlike a random forest, where more trees mostly just stabilise
    3. C. It always underfits
    4. D. It turns into a random forest
    View answer

    ✓ B. It can overfit, unlike a random forest, where more trees mostly just stabilise

    Boosting keeps fitting the residuals, eventually including noise. Use a small learning rate plus early stopping.

    Lesson: Gradient Boosting

  7. Question 7 of 9

    Which statement about bagging and boosting is correct?

    1. A. Both mainly reduce bias
    2. B. Bagging mainly reduces variance; boosting mainly reduces bias
    3. C. Bagging trains trees in sequence
    4. D. Boosting trains trees independently
    View answer

    ✓ B. Bagging mainly reduces variance; boosting mainly reduces bias

    Bagging averages independent strong learners; boosting adds weak learners in sequence to fix errors.

    Lesson: Ensembles: Voting, Stacking and Bagging vs Boosting

  8. Question 8 of 9

    When does combining models help the most?

    1. A. When the models make the same mistakes
    2. B. When the models are accurate and their errors are not correlated
    3. C. When you use many copies of one model
    4. D. Never
    View answer

    ✓ B. When the models are accurate and their errors are not correlated

    Averaging cancels independent errors. Models that fail on the same cases add nothing.

    Lesson: Ensembles: Voting, Stacking and Bagging vs Boosting

  9. Question 9 of 9

    In stacking, what should the meta-model be trained on?

    1. A. The base models' predictions on their own training data
    2. B. Out-of-fold predictions from the base models
    3. C. The raw features only
    4. D. The test set
    View answer

    ✓ B. Out-of-fold predictions from the base models

    Predictions on data a base model was trained on are over-optimistic; out-of-fold ones avoid that leakage.

    Lesson: Ensembles: Voting, Stacking and Bagging vs Boosting
