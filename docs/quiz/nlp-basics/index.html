NLP basics

12 questions on NLP basics, from 14 lessons. Pick an answer in your head, then open it.

On the roadmap for: AI Engineering, Data Science.

  1. Question 1 of 12

    Why can removing stop words hurt a sentiment model?

    1. A. It makes text longer
    2. B. Stop-word lists often include words like 'not', which flip the meaning
    3. C. Stop words carry the sentiment scores
    4. D. It doesn't
    View answer

    ✓ B. Stop-word lists often include words like 'not', which flip the meaning

    'Not good' becomes 'good'. Preprocessing choices should be tested against the task.

    Lesson: Text Preprocessing

  2. Question 2 of 12

    What does TF-IDF do that raw word counts don't?

    1. A. Removes all common words
    2. B. Down-weights words that appear in many documents, so distinctive words count more
    3. C. Uses word order
    4. D. Learns embeddings
    View answer

    ✓ B. Down-weights words that appear in many documents, so distinctive words count more

    A word like 'the' appears everywhere and gets a low IDF; a rare, specific word gets a high one.

    Lesson: Bag-of-Words, N-grams and TF-IDF

  3. Question 3 of 12

    Why does a unigram model misread 'not good', and what fixes it?

    1. A. It can't read short text; use longer text
    2. B. It sees 'not' and 'good' separately; adding bigrams captures 'not good' as one feature
    3. C. It needs stemming
    4. D. It ignores adjectives
    View answer

    ✓ B. It sees 'not' and 'good' separately; adding bigrams captures 'not good' as one feature

    Bigrams keep local word order that changes meaning.

    Lesson: Text Classification: Naive Bayes vs Logistic Regression

  4. Question 4 of 12

    What assumption does Naive Bayes make about words?

    1. A. Words are ordered
    2. B. Words are conditionally independent given the class
    3. C. All words are equally likely
    4. D. Only nouns matter
    View answer

    ✓ B. Words are conditionally independent given the class

    The assumption is wrong for language but makes the model fast and surprisingly strong on small data.

    Lesson: Text Classification: Naive Bayes vs Logistic Regression

  5. Question 5 of 12

    How does LDA describe a collection of documents?

    1. A. One label per document
    2. B. Each document is a mixture of topics, and each topic is a distribution over words
    3. C. A tree of documents
    4. D. A list of keywords
    View answer

    ✓ B. Each document is a mixture of topics, and each topic is a distribution over words

    It is unsupervised: you choose the number of topics, and it finds the word groups.

    Lesson: Topic Modelling: LDA, NMF and BERTopic

  6. Question 6 of 12

    What does perplexity measure for a language model?

    1. A. Its size
    2. B. How surprised it is by test text: the exponential of the average negative log-likelihood per token
    3. C. Its speed
    4. D. Its vocabulary size
    View answer

    ✓ B. How surprised it is by test text: the exponential of the average negative log-likelihood per token

    Lower is better. Perplexity k is like choosing uniformly among k tokens at each step.

    Lesson: N-gram Language Models and Perplexity

  7. Question 7 of 12

    How is the edit (Levenshtein) distance between two words computed?

    1. A. By counting letters
    2. B. As the minimum number of insertions, deletions and substitutions, using dynamic programming
    3. C. By comparing first letters
    4. D. By their embeddings
    View answer

    ✓ B. As the minimum number of insertions, deletions and substitutions, using dynamic programming

    A table builds up the distance between every pair of prefixes.

    Lesson: Edit Distance and Spelling Correction

  8. Question 8 of 12

    How does an LLM handle a word it has never seen?

    1. A. It skips it
    2. B. Subword tokenisation (e.g. BPE) splits it into known pieces
    3. C. It replaces it with [UNK] always
    4. D. It crashes
    View answer

    ✓ B. Subword tokenisation (e.g. BPE) splits it into known pieces

    BPE builds a vocabulary by merging frequent character pairs, so any word can be spelled with subwords.

    Lesson: Subword Tokenisation (BPE, WordPiece, SentencePiece)

  9. Question 9 of 12

    Why is named entity recognition scored with entity-level F1 rather than per-token accuracy?

    1. A. It's faster
    2. B. Most tokens are not entities, and a half-correct span is still wrong; entity F1 counts exact spans
    3. C. Tokens have no labels
    4. D. Accuracy can't be computed
    View answer

    ✓ B. Most tokens are not entities, and a half-correct span is still wrong; entity F1 counts exact spans

    Token accuracy looks high just by predicting 'O' (outside) everywhere.

    Lesson: Sequence Labelling and NER

  10. Question 10 of 12

    What does the Viterbi algorithm find?

    1. A. The most common word
    2. B. The single most likely sequence of hidden labels for the whole sentence, using dynamic programming
    3. C. The topic of a document
    4. D. The edit distance
    View answer

    ✓ B. The single most likely sequence of hidden labels for the whole sentence, using dynamic programming

    It's used in HMMs and CRFs to label every word at once rather than one at a time.

    Lesson: HMMs, CRFs and the Viterbi Algorithm

  11. Question 11 of 12

    How is BERT pretrained?

    1. A. Predicting the next word left to right
    2. B. Masking some tokens and predicting them from context on both sides
    3. C. Translating sentences
    4. D. Classifying documents
    View answer

    ✓ B. Masking some tokens and predicting them from context on both sides

    Masked language modelling gives bidirectional representations that adapt well to classification and tagging.

    Lesson: BERT and Masked Language Models

  12. Question 12 of 12

    Why can BLEU score a word salad above a correct paraphrase?

    1. A. BLEU uses meaning
    2. B. It counts n-gram overlap with the reference, so matching words in a bad order can beat different but correct wording
    3. C. BLEU prefers short answers only
    4. D. It can't
    View answer

    ✓ B. It counts n-gram overlap with the reference, so matching words in a bad order can beat different but correct wording

    Overlap metrics don't understand meaning; use them with care or alongside human or model-based judgements.

    Lesson: NLP Evaluation: BLEU, ROUGE, EM/F1
