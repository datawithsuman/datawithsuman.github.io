  1. Question 1 of 7

    What makes operating LLM apps different from classic ML ops?

    1. A. There are no deployments
    2. B. LLMs never change
    3. C. Nothing
    4. D. Prompts, models and retrieval all change behaviour, outputs are open-ended, and quality needs evals rather than one accuracy number
    View answer

    ✓ D. Prompts, models and retrieval all change behaviour, outputs are open-ended, and quality needs evals rather than one accuracy number

    Version prompts and configs like code, and test changes against evaluation sets.

    Lesson: LLMOps: What's Different

  2. Question 2 of 7

    Users say the assistant 'got worse this week', but all dashboards are green. What should you have been recording?

    1. A. Only error rates
    2. B. CPU usage only
    3. C. Nothing, it's subjective
    4. D. Full traces (inputs, retrieved context, tool calls, outputs, versions) plus quality signals such as evals and user feedback
    View answer

    ✓ D. Full traces (inputs, retrieved context, tool calls, outputs, versions) plus quality signals such as evals and user feedback

    Uptime and latency can be fine while answers degrade; you need traces to find what changed.

    Lesson: Tracing and Observability for LLM Apps and Agents

  3. Question 3 of 7

    Your provider retires your model in 60 days, and the replacement scores higher on benchmarks. How do you migrate safely?

    1. A. Switch on day 59
    2. B. Run your own eval set on the new model, adjust prompts, then roll out gradually while comparing results
    3. C. Keep using the old model
    4. D. Trust the benchmarks
    View answer

    ✓ B. Run your own eval set on the new model, adjust prompts, then roll out gradually while comparing results

    Public benchmarks don't measure your task; your evals and a staged rollout do.

    Lesson: Model Upgrades and Retirements

  4. Question 4 of 7

    Why can't input filters alone stop prompt injection?

    1. A. Filters block all text
    2. B. Prompt injection isn't real
    3. C. Attacks can be phrased endlessly and hidden in retrieved content, so the main defence is limiting what the model can access and do
    4. D. Filters are too slow
    View answer

    ✓ C. Attacks can be phrased endlessly and hidden in retrieved content, so the main defence is limiting what the model can access and do

    Treat model output as untrusted, give tools least privilege, and require approval for risky actions.

    Lesson: Guardrails and Prompt Injection

  5. Question 5 of 7

    Which approach typically cuts an LLM bill the most without losing quality?

    1. A. Turn off logging
    2. B. Route easy requests to smaller models, cache repeated prompts and answers, and batch offline work
    3. C. Always use the biggest model
    4. D. Raise max tokens
    View answer

    ✓ B. Route easy requests to smaller models, cache repeated prompts and answers, and batch offline work

    Most traffic doesn't need the strongest model; routing and caching remove most of the cost.

    Lesson: Cost and Latency: Routing, Caching and Batching

  6. Question 6 of 7

    Your LLM provider returns overload errors at peak time, and your retries make it worse. What should the client do?

    1. A. Switch off timeouts
    2. B. Retry immediately in a loop
    3. C. Send requests twice
    4. D. Use exponential backoff with jitter, respect Retry-After, cap retries, and fall back or shed load
    View answer

    ✓ D. Use exponential backoff with jitter, respect Retry-After, cap retries, and fall back or shed load

    Synchronised instant retries create a retry storm; spreading and limiting them lets the service recover.

    Lesson: LLM API Reliability: Rate Limits, Retries and Fallbacks

  7. Question 7 of 7

    A RAG app keeps citing an outdated policy page that was updated last week. Where is the likely problem?

    1. A. The LLM's training data
    2. B. The temperature
    3. C. The UI
    4. D. The index wasn't refreshed, so old chunks are still being retrieved
    View answer

    ✓ D. The index wasn't refreshed, so old chunks are still being retrieved

    Incidents like stale citations point at the data pipeline, not the model.

    Lesson: GenAI App Scenarios: Set 1
