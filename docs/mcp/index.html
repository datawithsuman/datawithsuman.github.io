MCP SERVER

AIML Rounds in your AI assistant.

Connect AIML Rounds to your AI assistant and prepare for AI/ML interviews in the chat. Free, no sign-in.

What it is

MCP (Model Context Protocol) lets an AI assistant use outside tools. Add the AIML Rounds server and your assistant can search the lessons, quiz you, run mock interviews and find jobs, answering from the site instead of from memory, with links to the pages.

  • Address: https://mcp.aimlrounds.com/mcp
  • Free and read-only. No sign-in, no API key.
  • Listed in the official MCP Registry as com.aimlrounds/aimlrounds. Servers at any other address aren't run by this site.

Add it

Run this once in your terminal. It adds the server for all your projects.

claude mcp add --transport http --scope user aimlrounds https://mcp.aimlrounds.com/mcp

Check it with /mcp inside Claude Code.

  1. In Claude (web or desktop), open Settings, then Connectors.
  2. Choose Add custom connector.
  3. Name it AIML Rounds and paste this address:
https://mcp.aimlrounds.com/mcp

On the free plan you can add one custom connector.

Add to Cursor

Or add this to ~/.cursor/mcp.json:

{
  "mcpServers": {
    "aimlrounds": {
      "url": "https://mcp.aimlrounds.com/mcp"
    }
  }
}

Add this to .vscode/mcp.json in your project, then start the server from that file.

{
  "servers": {
    "aimlrounds": {
      "type": "http",
      "url": "https://mcp.aimlrounds.com/mcp"
    }
  }
}

Run this once in your terminal.

codex mcp add aimlrounds --url https://mcp.aimlrounds.com/mcp

Or add it to ~/.codex/config.toml:

[mcp_servers.aimlrounds]
url = "https://mcp.aimlrounds.com/mcp"

Then just ask

Use plain words. If your assistant doesn't pick the server on its own, add “from aimlrounds” to your message.

  • “Quiz me on RAG, one question at a time.”A quiz from the site. It waits for your answer, then explains.
  • “Run a mock ML system design interview for an ML engineer.”A mock round. Answer in your own words and get feedback against the model answer.
  • “Explain the KV cache from aimlrounds.”The lesson, explained in the chat, with a link to the page.
  • “Make a 6-week study plan for an AI engineer role.”A plan built from the role roadmap, with lessons, quizzes and mocks.
  • “Show new GenAI jobs in Bengaluru for 2–5 years of experience.”Postings from the last 7 days, with direct links to apply.
  • “What's new on aimlrounds this week?”Lessons, designs and quizzes added recently.

Guided prompts

Some apps list these as ready-made prompts. In Claude Code, type /mcp__aimlrounds__study_topic and so on. In other apps, ask for them by name.

  • study_topicLearn one topic from the lessons, then check yourself with its quiz.
  • mock_interviewA mock interview for a role, one question at a time, with feedback.
  • study_planA week-by-week plan from the role roadmap.
  • job_prepFind matching jobs, then map what they ask for to lessons to revise.

Tools

Your assistant picks these for you. They're listed here so you know what it can do.

  • searchFind lessons by keywords or an interview question.
  • get_lessonRead a lesson, or one tab of it, such as the interview answer.
  • browseThe site's tracks, parts and sections.
  • roadmapThe study roadmap for AI Engineer, ML Engineer or Data Scientist.
  • quizMultiple-choice questions per topic. Answers stay hidden until you've answered.
  • mock_interviewMock rounds per role, with model answers for feedback.
  • jobsAI/ML jobs in India from the last 7 days. Filter by skill, company, city or experience.
  • whats_newWhat was added to the site recently.
