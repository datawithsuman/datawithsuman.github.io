Transcoders and Attribution Graphs

Built from Barez et al., Understanding AI from the Inside (arXiv 2611.08438) and 7 more sources · checked 13 Nov 2026
In one breath: A transcoder replaces an MLP with a sparse, readable stand-in that maps the MLP's input to its output, so feature-to-feature wiring can be read from the weights. A cross-layer transcoder lets each feature write to every later layer, giving a replacement model for all the MLPs. An attribution graph uses it for one prompt: features are nodes, direct effects are edges, and the graph is pruned to what matters.

1 · The problem

An SAE on each side of an MLP doesn’t tell you how the MLP connects them

Suppose you have SAE features before an MLP and after it, and want to know which input features cause which output features. The MLP sits in between, with thousands of neurons each applying its own nonlinearity. Gradient or patching attributions through it depend on the specific input, so you only learn about one example at a time, never the MLP’s general behaviour Dunefsky et al. §3.2. The survey puts it simply: SAEs “do not explain the nonlinear transformations … themselves that produce the activations” p. 41.

3 · Cross-layer transcoders
read once, write to every later layer

One feature, many destinations

A cross-layer transcoder (CLT) reads features from the residual stream at layer ℓ, and each feature has a separate decoder vector into the MLP output of every later layer. The reconstructed MLP output at layer ℓ′ sums contributions from all earlier layers’ features p. 42:

    Survey §6.6.2 p. 42.

    Why this helps: a feature doesn’t need to be re-encoded at every layer, so circuits get simpler, and with MLPs replaced the rest of the computation becomes roughly linear. That makes clean attribution possible p. 44.

    Swipe sideways to see the whole diagram.
    1. Start from the original model: attention and MLP blocks.
    2. Replace every MLP with the CLT’s features, which read the stream and write to the current and all later layers.
    3. Keep attention, but freeze its patterns (and the normalisation statistics) at the values from the original forward pass. The CLT does not model attention at all.
    4. Add an error term at each layer for whatever the CLT failed to rebuild. With these, the replacement exactly reproduces the original on this one prompt.
    5. Remove the crutches and swap the CLT in for real, and the replacement model’s top prediction matches the original on only about 50% of prompts from the Pile, in an 18-layer model survey p. 43.
    1 · The crosscoder

    Encode all layers together, decode each separately

      Survey §6.6.3 p. 45. The sparsity penalty weights each feature by the sum of its decoder norms across layers.

      • Causal crosscoders read only layers up to the current one, respecting the forward pass.
      • Acausal crosscoders read any layer, which is useful for describing feature relationships across the whole model after the fact p. 46.

      2 · Uses and pitfalls

      Simpler circuits, and comparing models

      Because one latent can stand for a feature at every layer, crosscoders remove duplicate copies that clutter circuits. Features can “jump” across intervening layers that just pass them along, and you can see which features persist unchanged and which get actively transformed p. 46.

      Train one crosscoder on two models (say a base model and its fine-tuned version), and features whose decoder strength is large in only one model are candidates for what fine-tuning added p. 45.

      False positives

      Crosscoders trained with an L1 penalty can falsely report features as unique to one model. BatchTopK helps but doesn’t eliminate it: a feature whose direction merely rotated during fine-tuning can look new. Treat “model-exclusive” features as hypotheses to test p. 79.

The graph’s nodes also include token embeddings, error nodes (what the CLT failed to rebuild) and output logits Ameisen et al..

        2 · The transcoder
        imitate the MLP, sparsely

        Learn a wide, sparse MLP that copies the real one

          Survey §6.6.1 p. 41.

            4 · The price
            quadratic cost · fidelity to check

            Parameters grow with depth squared

            With L layers, model width d and expansion factor e, a full CLT has L encoders and L(L+1)/2 layer-pair decoders. Ignoring biases, that is N = (e·d²/2)(L² + 3L) p. 44. Training the CLTs for Gemma-2-9B took about 3,844 H100 GPU-hours p. 44.

            —

            Survey formula (§6.6.2, Fig. 8), computed in your browser. Memory assumes 2 bytes per parameter.

            Fidelity caveats the survey lists

            • Results come mainly from small models, on short sequences from the CLT’s own training data; behaviour under distribution shift isn’t well tested.
            • The headline metric is top-1 agreement; softer metrics (top-5, KL divergence) may tell a different story.
            • Exact matching requires frozen attention, cached normalisation and per-layer error terms.
            • Fidelity is higher in middle layers, and on factual recall and syntax than on reasoning or arithmetic.

            pp. 43–44

            This scarcity shows in practice: the survey counts only a handful of downstream CLT applications so far (a greater-than mechanism study, an open-source extension, multilingual analysis) p. 44. CLTs come back in Activation Patching and Circuit Discovery as the engine of attribution graphs.

            3 · What the graph does and doesn’t show

            Limits

            • It explains the replacement model. CLTs only approximate the MLPs (a full replacement matches the top-1 prediction on about 50% of prompts in an 18-layer model), so the graph may cover only part of the real mechanism pp. 43, 57.
            • Attention is frozen: the graph shows what flows through attention, not why attention looked where it did p. 44.
            • The authors report satisfying insight on only a minority of prompts tried (secondary summaries say about a quarter) Lindsey et al. 2025.

            What it gives in return: readable, prompt-specific mechanisms such as the two-hop Dallas → Texas → Austin reasoning in Claude 3.5 Haiku (The Residual Stream and Circuits), where intervening on the intermediate “Texas” features changes the answer Lindsey et al. 2025.

            Anthropic introduced attribution graphs with cross-layer transcoders in March 2025 and used them on Claude 3.5 Haiku. On 29 May 2025 it open-sourced the circuit-tracer library, which builds graphs for open models such as Gemma-2-2B and Llama-3.2-1B, with an interactive front end on Neuronpedia. Neuronpedia reported almost 5,000 graphs generated by users soon after launch.

            Google DeepMind's Gemma Scope 2 (December 2025) added skip-transcoders and cross-layer transcoders for every Gemma 3 model, so you can trace multi-step computations in models up to 27B parameters.

            Say it in an interview

            The 30-second answer

            An SAE describes what a layer contains, but a transcoder describes what an MLP does: it maps the MLP's input to its output through sparse, readable features, so feature-to-feature wiring can be read from the weights. A cross-layer transcoder lets each feature write to every later layer, which gives a replacement model for all the MLPs. An attribution graph uses that for one prompt: nodes are features, and edges are direct effects through the frozen residual stream and attention. It's rich but approximate, so I'd prune it and check the main paths with interventions on the real model.

            Why are transcoder circuits easier to read than SAE circuits?

            Between SAEs on two layers, the connection passes through the MLP's nonlinearity and depends on the input. Transcoder features connect through fixed weights.

            What are error nodes?

            The part of each MLP's output the transcoder fails to reconstruct. They keep the graph adding up, but they're unexplained computation.

            What does a crosscoder add?

            One dictionary across layers removes duplicate copies of a feature at every depth, and one across two models supports model diffing.
